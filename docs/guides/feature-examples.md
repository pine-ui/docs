# Runnable examples

The package contains two updated samples: Counter and Component composition. Import one App entry per project. The Composition sample demonstrates generated MonoBehaviours, independent and shared sources, plain functions, callback props and multiple nesting levels.

[Counter App.cs](/examples/1.0.0/Counter/App.cs). Composition source: [App.cs](/examples/1.0.0/Composition/App.cs), [Counter.cs](/examples/1.0.0/Composition/Counter.cs), [Card.cs](/examples/1.0.0/Composition/Card.cs), [Actions.cs](/examples/1.0.0/Composition/Actions.cs).

All 1.0.0 downloads match this native API. Browser previews model behavior; they do not execute Unity or certify rendering.

## Run the example

Import the four Composition files together; Counter App.cs is a separate application.

[Controls](/examples/1.0.0/controls/PineControls.cs) · [Controls App.cs](/examples/1.0.0/controls/App.cs). The controls example demonstrates editable source write-back and same-object effects.
